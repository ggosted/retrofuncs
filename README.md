# retrofuncs
Данный скрипт предназначен для автоматизации взаимодействия с элементами интерфейса в SodaHotel. 

Основные селекторы (SELECTORS)

Объект, содержащий CSS-селекторы для доступа к различным элементам интерфейса:
Ключ	Описание
credits	Селектор для получения количества кредитов
diamonds	Селектор для получения количества алмазов
info_container	Контейнер с информацией об объекте
selected_player_achievments	Достижения выбранного игрока
selected_object_name	Имя выбранного объекта
selected_object_desc	Описание выбранного объекта
selected_object_owner	Владелец выбранного объекта
furni_button	Кнопки действий с мебелью
menu_button	Кнопки меню
avatar	Селектор аватара игрока
buybutton	Кнопка покупки
bot_bagde	Значок бота
Вспомогательные функции


openCatalog()

Открывает каталог, если контейнер открыт, объект доступен для покупки и является мебелью.

    Возвращает: true - если успешно, иначе false

actionWithFurni(action)

Выполняет действие с мебелью.

    Параметры: action - строка с названием действия ("Move", "Rotate", "Pick up", "Use")

    Возвращает: true - если действие выполнено, иначе false

getButtonsNameMap(selector)

Создает Map-объект из кнопок, где ключ - текст кнопки, значение - DOM-элемент.

    Параметры: selector - CSS-селектор для поиска кнопок

    Возвращает: Map объект

delay(ms)

Создает задержку выполнения.

    Параметры: ms - время задержки в миллисекундах

    Возвращает: Promise

Функции проверки состояния
isContainerOpen()

Проверяет, открыт ли контейнер с информацией.

    Возвращает: true - открыт, false - закрыт

isHaveRights()

Проверяет, есть ли у пользователя права на управление объектом.

    Возвращает: true - права есть, false - прав нет, null - контейнер закрыт

isBot()

Проверяет, является ли выбранный объект ботом.

    Возвращает: true - является ботом, false - не является

isPlayer()

Проверяет, является ли выбранный объект игроком.

    Возвращает: true - является игроком, false - не является

isFurni()

Проверяет, является ли выбранный объект мебелью.

    Возвращает: true - является мебелью, false - не является

isBuyable()

Проверяет, можно ли купить выбранный объект.

    Возвращает: true - можно купить, false - нельзя

isUsable()

Проверяет, доступно ли действие "Использовать" для выбранной мебели.

    Возвращает: true - доступно, false - недоступно

Функции получения данных
getCredits()

Возвращает количество кредитов.

    Возвращает: строка с числом кредитов

getDiamonds()

Возвращает количество алмазов.

    Возвращает: строка с числом алмазов

getSelectedPlayerAchievments()

Возвращает достижения выбранного игрока.

    Возвращает: строка с достижениями или null если выбран не игрок

getSelectedObjectName()

Возвращает имя выбранного объекта.

    Возвращает: строка с именем или null если контейнер закрыт

getSelectedObjectDesc()

Возвращает описание выбранного объекта.

    Возвращает: строка с описанием или null если контейнер закрыт

getSelectedObjectOwner()

Возвращает владельца выбранного объекта.

    Возвращает: строка с именем владельца или null если контейнер закрыт или выбран игрок


Класс Furni

Представляет объект мебели.

Свойства:

    name - имя мебели

    desc - описание

    owner - владелец

    usable - доступность использования (true/false)

    purchasable - доступность покупки (true/false)

Статический метод:

    create() - создает экземпляр класса, если выбранный объект является мебелью. Возвращает null в противном случае.

Класс Player

Представляет игрока.

Свойства:

    nick - никнейм игрока

    motto - девиз/статус игрока

    achievments - достижения

Статический метод:

    create() - создает экземпляр класса, если выбранный объект является игроком. Возвращает null в противном случае.

Класс myPlayer (наследуется от Player)

Расширяет класс Player методами для управления своим персонажем.

Методы:
changeClothes()

Открывает меню смены одежды.

    Возвращает: true - успешно, false - ошибка

changeMyDance(style, dance)

Меняет танец персонажа.

    Параметры:

        style - стиль танца

        dance - конкретный танец

    Возвращает: true - успешно, false - ошибка

changeMyAction(action)

Выполняет действие персонажа.

    Параметры: action - название действия

    Возвращает: true - успешно, false - ошибка

showSign(line, number)

Показывает знак/табличку.

    Параметры:

        line - номер строки в меню знаков

        number - номер знака в строке

    Возвращает: true - успешно, false - ошибка

Класс Bot

Представляет бота.

Свойства:

    name - имя бота

    motto - девиз/статус бота

    owner - владелец бота

Статический метод:

    create() - создает экземпляр класса, если выбранный объект является ботом. Возвращает null в противном случае.
